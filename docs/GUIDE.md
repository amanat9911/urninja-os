# UrNinja OS — Guide (Hinglish)

## Ye app kya hai?
UrNinja OS ek agency operating system hai — team, sales, tasks, attendance, payroll, clients, tickets aur finance sab ek jagah.
Abhi ye **demo mode** mein hai: saara data aapke browser mein save hota hai, koi real server nahi hai.

## Kaise use karein
- **Login:** koi bhi employee chuno, koi bhi password (4+ characters) chalega.
- **Role switch:** upar wale dropdown se Owner/HR/Employee ban kar dekh sakte ho.
- **Reset Demo Data:** sidebar ke neeche — sab kuch original sample data par wapas.
- **Dark mode:** upar chaand/suraj icon.

## Modules
| Page | Kya kar sakte ho |
| --- | --- |
| Dashboard | KPIs, pipeline chart, tasks, activity |
| Employees | Search, add, profile, ID card print |
| Departments | Hierarchy, naya department |
| Roles & Access | Permission matrix (abhi sirf dikhane ke liye) |
| Leads | Kanban board, call log, CSV import, client convert |
| Tasks | Assign → Start → Submit → Approve/Reject, announcements |
| Attendance | Check-in/out, leave apply, 4-level approval |
| Payroll | Monthly sheet, incentives, approval flow, salary slip |
| Clients | Services, deliverables, timeline |
| Tickets | Assign, status, SLA, internal notes |
| Finance | Invoices, payment record, expenses, profit |
| Performance | Leaderboard (demo formula) |
| Audits & Docs | Audit scores, document list |
| Activity Log | Har action ka record |
| Settings | Company, holidays, leave policy, lead sources |
